# ⚙ CF-SUB

**CF-SUB** 是一个将多个节点和机场订阅合并为单一链接的高级聚合工具，支持客户端自动适配与自定义分流，极致简化了订阅管理体验。

本项目基于 [cmliu/CF-Workers-SUB](https://github.com/cmliu/CF-Workers-SUB) 进行深度重构开发。在保留其核心聚合转换能力的基础上，**剔除了繁冗的 Telegram 依赖**，实现了真正的极速轻量化，并打造了完善的网页可视化管理系统与安全防护机制。（特此感谢原作者 cmliu 的开源贡献 🍻）

> [!CAUTION]
> **汇聚订阅非 base64 订阅时**，会自动生成一个**有效期为 24 小时的临时订阅**，并提交给**订阅转换后端**来完成订阅转换，可避免您的汇聚订阅地址泄露。

> [!WARNING]
> **汇聚订阅非 base64 订阅时**，如果您的节点数量十分庞大，订阅转换后端将需要较长时间才能完成订阅转换，这会导致部分梯子客户端在订阅时提示超时而无法完成订阅。
>
> 可自行在后台删减订阅节点数量，提高订阅转换效率！

## ✨ 核心特性
1. **多端自适应分发**：只需一个极简链接（如 `https://域名/token`），浏览器打开即为管理后台，代理客户端拉取自动识别下发对应格式（Base64 / Clash / Sing-box / Surge / Loon）。
2. **可视化管理后台**：彻底告别繁琐的 CF 环境变量修改！绑定 KV 空间后，直接在网页后台通过可视化弹窗管理节点订阅、安全鉴权、转换后端（SUBAPI）、分流规则（SUBCONFIG）及去广告过滤词（NOADS）。
3. **强大的主页伪装保护**：直接打开域名或输入错误路径时，系统提供四种防嗅探模式（原生 NGINX 兜底、URL 网页反代、302 重定向、自定义 HTML）。完美隐藏背后的订阅服务，防止被爬虫扫描。
4. **后端连通性实时检测**：后台自动检测当前自定义的 SUBAPI 和 SUBCONFIG 是否有效。若发生超时或失效，UI 界面会直观提示，并**自动无缝回退**至内置的官方转换通道，确保订阅永远可用。
5. **双通道安全独立**：支持设置“管理员”与“访客”两个独立入口。访客入口仅提供节点拉取与纯净版状态分享页，无法访问配置后台，方便安全地分享给他人使用。自带“一键安全退出”功能，保护后台环境。

## 📦 部署与配置步骤

无论是使用 Cloudflare Pages 还是 Workers 部署，**设置 TOKEN 环境变量**和**绑定 KV 空间**都是实现安全访问与配置永久保存的核心。请根据你的部署方式参考以下步骤：

### 方式一：Pages 部署（小白推荐 ✨）
1. **部署代码**：Fork 本仓库，在 CF Pages 中连接你的 GitHub 仓库进行部署。（💡 **小贴士**：在初次部署的设置页面中直接提前填好下面的 `TOKEN` 变量，就可以一步到位，无需后续重新部署。）
2. **设置环境变量（⚠️ 必做）**：进入 Pages 项目详情页 -> `设置` -> `环境变量`，添加变量名称为 `TOKEN`，值为你自定义的后台入口路径（例如 `mytoken`）。**【注意：如果你是在首次部署完成后才添加的 TOKEN，必须前往“部署”页面点击“重试部署”才能使其生效！】**
3. **绑定 KV 空间（⚠️ 必做）**：
   - 在 Cloudflare 侧边栏找到 `存储和数据库` -> `KV`，创建一个命名空间（名字随意）。
   - 进入你的 Pages 项目详情页 -> `设置` -> `绑定` -> `KV 命名空间`，添加绑定，**变量名称必须严格填入 `KV`**。（同样，如果部署完成后才绑定 KV，也需要重试部署）。
4. **域名设置（⭕ 选做）**：官方自带的 `.pages.dev` 域名目前国内可直连访问，**无需绑定自定义域名即可直接使用**。如需使用自己的域名，可在项目的 `自定义域` (Custom Domains) 中添加。

### 方式二：Workers 部署
1. **部署代码**：新建 CF Worker，直接复制粘贴 `_worker.js` 代码并部署。
2. **设置环境变量（⚠️ 必做）**：进入 Worker 项目详情页 -> `设置` -> `变量和机密`，添加变量名称为 `TOKEN`，值为你自定义的后台入口路径（例如 `mytoken`）。
3. **绑定 KV 空间（⚠️ 必做）**：
   - 在 Cloudflare 侧边栏找到 `存储和数据库` -> `KV`，创建一个命名空间（名字随意）。
   - 进入你的 Worker 项目详情页 -> `设置` -> `绑定` -> `KV 命名空间`，添加绑定，**变量名称必须严格填入 `KV`**。
4. **绑定自定义域名（✅ 必做）**：由于官方自带的 `.workers.dev` 域名在国内已经被墙，**必须**进入 Worker 详情页的 `触发器` (Triggers) -> `自定义域` 中，绑定你托管在 CF 的域名才能在国内正常访问。

## 📋 环境变量配置说明 (Cloudflare 后台仅留一个)

为了系统的绝对安全和核心入口控制，Cloudflare 后台的 **“环境变量 (Environment Variables)”** 中**只需保留最核心的 `TOKEN` 即可**：

| 变量名 | 说明 | 示例 | 是否必填 |
|------|------|------|--------|
| **TOKEN** | 管理员入口路径及后台登录总钥匙 | `mytoken` | ✅ 必填 |

*(注：各项详细参数已全部移至网页后台进行可视化动态管理，CF 环境变量中无需填写其它参数。)*

## 🖥️ 网页可视化后台配置 (登录网页后设置)

当你绑定了 `KV` 空间并在 CF 后台配置好 `TOKEN` 后，通过 `https://你的域名/你的TOKEN` 即可登录进入管理界面。

你可以在网页后台的 **“🏠 主页设置”**、**“🛡️ 安全设置”** 以及主面板中，**直接可视化修改**以下所有配置，修改后立刻生效并永久保存：

| 后台配置项 | 说明 | 示例推荐 |
|------|------|------|
| **主页模式** <br>`(Fake Mode)` | 提供 4 种防探测模式：<br>`[关闭]` 强制兜底显示 NGINX 测试页<br>`[URL]` 网页反向代理并自动注入标题<br>`[URL302]` 强制跳转到指定网站<br>`[HTML]` 完全自定义渲染 HTML 代码 | `[URL] 网页反向代理` -> `https://www.bing.com` |
| **访客订阅入口** <br>`(GUEST)` | 访客专用的独立分享路径（仅供客户端拉取节点，无法进入后台） | `guesttoken` |
| **后台鉴权账号** <br>`(USER / PASS)` | 网页后台管理员登录的用户名与密码 | `admin` / `123456` |
| **站点/订阅名称** <br>`(SUBNAME)` | 代理客户端中显示的订阅名称，以及网站首页的标题（Title） | `CF-SUB` |
| **订阅转换后端** <br>`(SUBAPI)` | 用于将通用 Base64 转换为各客户端专属格式的在线后端 API。**后台自带连通性检测。** | `SUBAPI.cmliussss.net` |
| **转换规则** <br>`(SUBCONFIG)` | 节点测速分组与分流规则配置文件链接。**后台自带有效性检测。** | `https://raw.../ACL4SSR_Mini.ini` |
| **去广告/屏蔽关键字** <br>`(NOADS)` | 填写关键字符，系统在下发前会自动屏蔽名称中包含这些字符的引流/广告节点（支持英文逗号、空格、换行分隔） | `加入TG群, YouTube, http://` |
| **汇聚订阅节点编辑** | 存放你的所有自建单节点（vless/vmess/trojan 等）或机场订阅链接（http），每行一个 | `vless://xxx...` <br> `https://...` |

## 🔗 支持的订阅格式与参数

本项目内置高级客户端自适应（User-Agent）识别功能。**通常情况下，你只需复制“自适应订阅地址”（如 `https://sub.example.com/mytoken`）填入客户端即可，系统会自动下发对应的格式。**

如果你的客户端比较冷门，或者你需要强制获取某种特定格式，也可以在链接末尾直接加上参数（进入你的网页后台点击对应按钮即可一键复制及生成二维码）：

| 订阅格式 | URL 参数后缀示例 | 适用客户端 | 说明 |
|------|------|------|------|
| **智能自适应** | `/mytoken` | 所有主流客户端 | **✨ 强烈推荐**！根据请求特征自动下发 |
| **Base64** | `/mytoken?b64` | v2rayN, v2rayNG 等 | 仅做节点聚合与过滤，纯节点 Base64 编码 |
| **Clash** | `/mytoken?clash` | Clash, Meta, Mihomo 等 | 附带全局测速分组与 SUBCONFIG 分流规则 |
| **Sing-box** | `/mytoken?sb` | Sing-box, NekoBox 等 | 附带全局测速分组与 SUBCONFIG 分流规则 |
| **Surge** | `/mytoken?surge` | Surge for Mac / iOS | 附带全局测速分组与 SUBCONFIG 分流规则 |
| **Loon** | `/mytoken?loon` | Loon 等 | 附带全局测速分组与 SUBCONFIG 分流规则 |

## 💡 使用方法示例

假设你的域名是 `sub.example.com`，管理员 TOKEN 是 `mytoken`，你在后台设置的访客 GUEST 是 `guesttoken`：

* **🌐 访问网页管理后台**：
  打开浏览器访问 `https://sub.example.com/mytoken`，输入你在后台设置的 USER 和 PASS 登录，即可进行节点添加和各项参数调整。离开时可点击右上角 `🚪 退出` 按钮安全注销。
* **🤝 分享给朋友的访客链接**：
  让朋友在客户端中订阅：`https://sub.example.com/guesttoken`（朋友只能拉取节点并查看当前 API 状态，无法进入后台乱改配置）。
* **🕵️ 防止陌生人偷窥**：
  如果其他人直接浏览器打开 `https://sub.example.com`，或者随便输错了路径，他们只会看到你在后台设置的伪装页面（如必应搜索页、Nginx 报错页或直接跳走），绝对猜不到这其实是个订阅服务。
